Getting started

OverviewProtocolSecurity
Use test data only. This firmware is a research demonstration, not a production PIN service.

Build locally

The repository includes a local PlatformIO virtual environment:

./venv/bin/pio run

The build covers the configured ESP32 and ESP32-S3 environments. GitHub Actions publishes the same images as a browser-flasher artifact.

First boot

  1. Flash the generated image using the browser flasher or PlatformIO.
  2. Connect to ESPinServer-Setup.
  3. Configure the local Wi-Fi network in the captive portal.
  4. Open http://espinserver.local/ or the device IP address.

Client configuration

Use the server public key shown on the Configuration page. Compatible clients send requests to /set_pin and /get_pin; see the protocol guide.

Resetting test data

The dashboard can wipe all PIN records. Generating a new server key invalidates clients using the previous public key.

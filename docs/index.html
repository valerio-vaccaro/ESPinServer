Research firmware for ESP32

ESPinServer

The ESP-based PinServer for local, Blockstream-style PIN-server research and DIY hardware.

OverviewGetting startedProtocolSecurity
Research use only. The PIN database is encrypted in LittleFS with a password-derived AES-256/HMAC-SHA256 key, but configuration and the server private key remain in ESP32 NVS. Do not use this firmware with production funds or real credentials.

Build, flash, connect to Wi-Fi, and run the local server.
